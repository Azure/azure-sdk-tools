# Coding-agent instructions

Before creating or modifying Python code in this subtree, read the local
`docs/python-coding-guidelines.md`, the shared
[Python coding guidelines](https://github.com/Azure/azure-sdk-tools/blob/main/tools/sdk-ai-bots/docs/python-coding-guidelines.md).
Apply its validation commands and incremental enforcement policy.

The same standard applies to human-written and agent-generated Python. Existing
implementations provide compatibility context, not a substitute for the standard.
Report the checks run and any unresolved compatibility conflicts in the PR.

These are development instructions, not instructions for the deployed chatbot.
For changes in other languages, follow the repository's existing guidance.
