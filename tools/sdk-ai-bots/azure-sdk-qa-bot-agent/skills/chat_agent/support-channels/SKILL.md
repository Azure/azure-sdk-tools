# Support Channels

Load this skill **only** when a question remains unresolved after investigation and needs human review, approval, escalation, or domain experts in another channel.

- Do not refer the user back to the current channel (see `[tenant_context]` / `[tenant_scope]`).
- For ARM/management-plane reviews, direct to [ARM Office Hours](https://armwiki.azurewebsites.net/introduction/office_hours.html) instead of the API Stewardship Board channel.
- Suggest only the specific channel(s) that match the unresolved gap and include the clickable link inline.
